# Dashboard de Ventas - Heladería 🍦

## Descripción General
Dashboard profesional de ventas para una heladería que proporciona una visualización completa del rendimiento de ventas y métricas clave del negocio.

## Componentes Principales

### 1. **Header (Encabezado)**
- Fondo azul profesional (#1A80CC)
- Título "Dashboard de Ventas - Heladería"
- Ubicado en la parte superior para una navegación clara

### 2. **KPI Cards (Tarjetas de Métricas Clave)**
Cuatro tarjetas mostrando métricas principales:

| Métrica | Valor | Icono |
|---------|-------|-------|
| Ventas Totales | $45,200 | 💰 |
| Transacciones | 1,256 | 📊 |
| Ticket Promedio | $36 | 🛒 |
| Clientes | 845 | 👥 |

Cada tarjeta:
- Diseño limpio y moderno
- Fondo blanco con bordes sutiles
- Color distintivo para cada métrica
- Valores numéricos destacados

### 3. **Gráfico de Ventas**
- Sección para visualizar tendencias de ventas
- Período de análisis: Últimos 7 días
- Área reservada para integración de gráficos (Chart.js, D3.js, etc.)
- Dimensiones: 650x200px

### 4. **Productos Más Vendidos**
Lista interactiva de los 4 productos top:

| Producto | Unidades | Porcentaje |
|----------|----------|------------|
| Helado de Vainilla | 245 | 85% |
| Helado de Chocolate | 198 | 68% |
| Sorbet de Fresa | 156 | 54% |
| Pistacho Gourmet | 142 | 49% |

Características:
- Barras de progreso visuales
- Número de unidades vendidas
- Porcentaje de popularidad

### 5. **Footer**
- Información de última actualización
- Versión del dashboard
- Texto subtle en gris

## Dimensiones y Especificaciones
- **Resolución**: 1400x900px
- **Tema de color**: Azul profesional (#1A80CC), verdes, naranjas y rosas
- **Tipografía**: Sans-serif
- **Espaciado**: Coherente y profesional

## Paleta de Colores
- **Primario (Ventas)**: #1A80CC (Azul)
- **Verde (Transacciones)**: #33B366 (Verde)
- **Naranja (Ticket)**: #E69A00 (Naranja)
- **Rosa (Clientes)**: #CC3366 (Rosa/Magenta)
- **Fondo**: #FAFBFF (Azul muy claro)
- **Texto**: #333333 (Gris oscuro)

## Cómo Usar Este Diseño

### En Figma
1. Accede al archivo en Figma: [Dashboard de Ventas - Heladería](https://www.figma.com/design/rnl3AzZoDMr51TA6mATHDi)
2. Personaliza colores y textos según necesidad
3. Exporta componentes para desarrollo

### Para Desarrollo Web
El dashboard puede implementarse usando:
- **Frontend**: React, Vue, Angular
- **Gráficos**: Chart.js, D3.js, ECharts
- **Estilos**: Tailwind CSS, Material-UI, Bootstrap
- **Backend**: APIs REST para datos en tiempo real
